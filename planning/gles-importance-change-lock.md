# Изменение важности темы отдельно от изменения позиции

Спецификация фиксируется после основных моделей GLES, до расчёта связи
изменений позиции и важности с голосованием. Сопоставляются вторая
и четвёртая волны кампании 2013 года. Для налогов/социальных расходов,
иммиграции и климата сохранены одинаковые вопросы: позиция по семибалльной
шкале и важность темы по пятибалльной.

Изменение важности не означает изменение позиции. Человек может по-прежнему
предпочитать ограничение иммиграции, но начать придавать этому вопросу
большее значение. Его выбор будет зависеть и от того, какую политику
предлагают партии. Поэтому одной средней связи важности с голосом мало:
модель допускает разную связь при разных позициях по той же теме.

## Основное сравнение

Для каждой темы используется модель четырёх исходов, с прежней
классификацией партий GLES. Первичная выборка требует исходного набора
установок, обеих позиций и обеих оценок важности, известного исхода
и отсутствия уже состоявшегося почтового голосования к четвёртой волне.
Все блоки внутри темы используют одинаковых людей. Дополнительно
оцениваются все три темы вместе на общем пересечении.

Исходное намерение берётся из второй волны, до интервала изменения.
Намерение четвёртой волны является отдельной более строгой проверкой.
Партийная идентичность и социальные контроли берутся из закреплённых
ранних измерений. Основной исходный вес остаётся `wei_mz`.

Последовательность блоков: ранние контроли, намерение, экономическая оценка
первой волны, ранняя позиция, ранняя важность и их взаимодействие;
затем поздняя позиция; затем поздняя важность и её взаимодействие
с поздней позицией. Учет раннего уровня позволяет интерпретировать
последний шаг как связь изменения важности при заданной позиции.
Три вопроса о правительственном и общем недоверии из третьей волны
добавляются отдельной проверкой. Они измерены внутри изучаемого интервала,
поэтому не называются исходными причинами изменения важности.

Первичная модель L2-логистическая, C=1. Дополнительные варианты C=0,1/10,
без весов, без исходного партийного намерения, с поздним намерением,
без взаимодействий, с недоверием третьей волны и строгой классификацией.
Фиксированная основная модель не выбирается по результатам этих вариантов.

Поздние уровни вместе с ранними алгебраически задают модель изменения:
поздний уровень равен раннему плюс изменение. Прогнозный контраст важности
составляет «скорее важно» вместо «ни важно, ни неважно», при сохранении
раннего ответа и поздней позиции. Он не выходит за границы шкалы даже
у людей с высокой исходной важностью. Для каждой темы показываются
усреднённая разница при наблюдаемых позициях и отдельные разницы
при позиции 2 и 6 на семибалльной шкале. Обе переменные взаимодействия
пересчитываются при изменении задаваемого уровня.

Интервалы: 1 000 повторных выборок людей. Предсказательная добавка:
пять частей по людям, log loss и Brier, сравнение поздней важности
с блоком поздней позиции, 2 000 повторений фиксированных отложенных
ошибок. Прежний критерий полезности 1% с положительной нижней границей
сохраняется. Условная связь не считается причинным воздействием важности.

## Описательная проверка изменений

Для каждой темы сохраняется таблица «позиция снизилась/не изменилась/выросла»
на «важность снизилась/не изменилась/выросла». На общей выборке трёх тем
считается число тем с ростом важности. Эти оценки абсолютные: все темы
могут одновременно стать важнее. Сдвиг ответа между двумя интервью
может включать ошибку измерения, а не только изменение предпочтения.

Связанные данные 2009/2013 используются отдельно, только через ZA5757.
Для налогов и иммиграции основное сравнение оставляет семибалльную
шкалу 2009 года; объединение с одиннадцатибалльной является чувствительностью.
Изменение климатической позиции между годами не оценивается как
одинаковое измерение из-за смены формулировки. Это малые и отобранные
подвыборки, их нельзя использовать вместо общего европейского теста.
